## 一、核心现状痛点（首次打开用户体验问题）
1. 无新手引导，纯空白引导文案，新用户不知道软件能做什么、文件存在本地哪里
2. 功能入口单薄，只有「新建笔记/打开侧边栏」两个操作，缺少快速上手路径
3. 技术水印干扰视觉，首次打开第一观感杂乱
4. 无价值信息输出，无法传递「本地MD知识库」核心定位，分不清和Typora/记事本区别
5. 无新手示例、模板、快速导入功能，从零开始门槛高
6. 侧边栏默认收起，新用户看不到文件夹结构，不懂文件管理逻辑
7. 无版本、本地存储路径提示，用户找不到自己存的笔记

## 二、分模块落地优化（UI+交互+文案，可直接落地）
### 1. 页面顶部导航栏优化（首次启动专属适配）
1. **侧边栏默认展开**
   首次打开强制展开左侧目录树，直观展示「文件夹管理MD」核心能力；后续启动记住用户收起状态。
2. 新增新手悬浮气泡引导（3步轻引导，3秒自动消失）
   - 气泡1：指向「+新建」按钮：「点击创建第一篇Markdown笔记」
   - 气泡2：指向左侧「我的文件夹」：「所有笔记自动保存在本地文件夹，不会丢失」
   - 气泡3：指向右上角搜索：「支持全文检索所有笔记内容」
3. 右上角新增「新手教程」快捷按钮，一键打开内置MD教程

### 2. 中间空白主区域（核心优化区，分层重构）
#### （1）移除杂乱日志水印，替换轻量化柔和背景
- 方案A：极简浅渐变底色，无任何水印；
- 方案B：低透明度软件Logo暗纹，提升品牌感不刺眼。

#### （2）页面分层结构：定位介绍区 + 快捷操作区 + 模板/示例区
##### 第一层：软件定位短句（替代单调标题）
原：当前没有打开的笔记
优化标题文案：
# 欢迎使用 MarkFlow 本地Markdown知识库
小字副标题：所有笔记仅保存在本地，轻量化技术文档、学习笔记编辑器

##### 第二层：双核心操作按钮（保留，强化视觉区分）
- 主按钮：紫色大号「新建空白笔记」
- 次要按钮：「导入本地.md文件」（新增！首次用户大概率已有存量笔记）
- 辅助文字补充：侧边栏可管理所有文件夹与笔记

##### 第三层：新手模板快捷栏（首次打开核心加分项）
横向卡片布局，一键新建带格式模板，降低从零创作门槛：
1. 技术开发文档模板（接口文档、故障排查记录）
2. 学习教程笔记模板（思维导图、知识点清单）
3. 日常随笔/工作计划模板
4. Agent AI 提示词模板（贴合截图内已有Agent文件夹，贴合用户群体）

##### 第四层：新手快速提示（小字轻量化提示）
- 提示1：本地存储路径：`C:/Users/xxx/Documents/MarkFlow笔记`（显示真实路径，解决用户找不到文件痛点）
- 提示2：支持深色/浅色主题切换（右上角太阳图标）
- 提示3：文件夹右侧数字=当前文件夹笔记总数

#### （3）底部新增「一键导入示例知识库」按钮
点击自动生成内置示例文件夹（Agent教程、Typora教程），和截图内目录结构对齐，用户打开就能看到完整示范目录，直观学会分类管理笔记。

### 3. 左侧侧边栏首次启动优化
1. 首次打开自动生成默认目录结构，无需用户手动创建：
   - 最新（系统自动分类）
   - 我的文件夹
     - 技术学习笔记
     - AI Agent教程
     - 随笔归档
   - 回收站
2. 侧边栏增加轻量提示气泡：「在这里管理所有本地笔记文件夹」
3. 标注本地仓库存储路径在侧边栏底部，随时查看

### 4. 交互细节体验优化
1. 记忆开关：「不再展示新手引导」勾选框，引导气泡、示例提示只在首次打开弹出
2. 快捷键提示悬浮窗：空白页右下角小浮窗，hover显示常用快捷键（新建、搜索、切换主题）
3. 多入口闭环：
   - 顶部「新建」
   - 中间主按钮「新建笔记」
   - 模板卡片「一键创建」
   三处入口功能统一，降低操作成本
4. 弱化无用元素：左下角「0字」仅打开文档后显示，空白首页隐藏，减少冗余信息

## 三、极简轻量化版本（不想大改界面，低成本优化）
如果不希望大幅改动现有布局，只做4处低成本优化：
1. 移除页面日志水印，纯白干净背景；
2. 标题增加欢迎文案，补充本地存储说明小字；
3. 新增「导入本地MD」按钮，和原有两个按钮并排；
4. 首次启动侧边栏默认展开，增加1个悬浮气泡指引新建；
5. 增加一行小字展示本地笔记存储文件夹路径。

## 四、商业/产品层面收益
1. 降低新用户流失：首次打开知道软件用途、文件存储位置、快速上手模板，不会因为空白页面直接关掉软件；
2. 强化差异化：突出「本地离线存储、技术知识库」定位，和在线笔记软件做出区分；
3. 降低学习成本：无需看外部教程，软件内自带示例+模板，开箱即用；
4. 贴合目标用户（程序员/技术学习者）：针对性提供开发、Agent相关模板，精准匹配需求。

## 1. 问题陈述

空库用户第一次打开 MarkFlow 时，无法在 10 秒内搞清三件事：**这是本地 Markdown 知识库**、**笔记存在哪**、**下一步点哪里**。

当前空态（`empty-tabs-state`）只有标题「当前没有打开的笔记」和两个按钮（新建笔记 / 从侧边栏打开）。更关键的是：无笔记时 `bootstrapAfterLoad()` 会自动创建并打开欢迎笔记，**空白首页几乎不是首启主路径**。

### 1.1 用户可感知现象

- 不知道和 Typora / 记事本的差别（本地知识库 vs 单文件编辑器）
- 找不到笔记存放位置（实际是 `utools.dbStorage`，不是磁盘 `.md` 目录）
- 不会用侧栏文件夹、搜索、导入
- 从零写第一篇的门槛高（无模板、无示例）
- 无打开文档时底栏仍显示「0 字」，空态显得未完成

### 1.2 非问题（本 PRD 不覆盖）

- 编辑器语法、预览、主题系统本身
- 把存储引擎改成「磁盘 Markdown 目录」（独立能力，另立 PRD）
- 已有笔记用户的日常工作流（搜索算法、侧栏性能等）
- 顶栏增加太阳图标切主题（架构约束：主题只在设置里）

## 2. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 全新安装用户 | 第一次打开，库内 0 篇笔记 | 看到空白首页，而不是被自动塞一篇欢迎笔记；10 秒内知道用途与下一步 |
| 有存量 `.md` 的用户 | 从 Typora / VS Code 迁过来 | 空态上直接「导入本地 .md」，不必翻「文件」菜单 |
| 想先看看长什么样的用户 | 不愿从零写 | 点模板或「一键导入示例知识库」，侧栏立刻出现可浏览的目录 |
| 关光标签的老用户 | 库里有笔记，但当前 0 个 Tab | 看到同一套空态，但**不弹**新手气泡、不强推示例库 |
| 已完成引导的用户 | 再次空库或关光标签 | 不再出现气泡；仍保留新建 / 导入 / 模板 |

## 3. 目标与非目标

### 3.1 目标

1. **空库首启进入空白首页**（停掉自动创建欢迎笔记）
2. **空态承担 onboarding**：定位文案 + 主操作 + 模板 + 存储说明
3. **导入入口前置**到空态，复用现有导入能力
4. **存储说明诚实**：写清 uTools 本地数据库 + 可导出 / 备份，禁止伪造 Documents 路径
5. **视觉对齐原型** [`docs/plans/ui/`](../plans/ui/)，沿用现有壳层（顶栏 / 侧栏 / 主色 `#5243E8`）
6. **引导可关闭且只出现一次**

### 3.2 非目标

- 不把笔记存储改成 `C:/Users/xxx/Documents/MarkFlow笔记`
- 不在顶栏加主题太阳图标
- 不自动静默生成示例文件夹（必须用户点击）
- 不重做「最新 / 我的文件夹 / 回收站」（已是系统结构）
- 本期不做空态右下角快捷键浮窗（P2，见 §8）

## 4. 产品决策（已拍板）

实施时按下列结论执行，不再按原始建议原文落地。

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 首启策略 | **方案 A：空白首页优先** | 自动欢迎笔记会挡住空态；教程改为顶栏按钮按需打开 |
| 存储文案 | 「保存在 uTools 本地数据库，可随时导出为 .md / 在设置中备份」 | 产品不是磁盘文件夹知识库；写死 Documents 路径会误导 |
| 默认目录 | 不自动创建「技术学习笔记」等真实文件夹 | 「最新 / 我的文件夹 / 回收站」已存在；示例结构改由用户点击导入 |
| 主题提示 | 指向右上角**设置** | 架构测试禁止顶栏主题快捷入口 |
| 水印 | 保持现有空态浅紫径向底，不加 Logo 暗纹 | 源码无「技术水印」；方案 B 品牌暗纹不做 |
| 视觉源 | UI 原型为准，原始建议为输入 | 原型已消化纠偏后的文案与信息架构 |

### 6.3 空态信息架构（Phase B，对齐原型 01）

1. **定位**
   - 标题：`欢迎使用 MarkFlow 本地 Markdown 知识库`
   - 副标题：`所有笔记仅保存在本机 uTools 数据库，可随时导出为 .md，适合技术文档与学习笔记`
2. **主操作**
   - 主按钮：`新建空白笔记`
   - 次按钮：`导入本地 .md 文件`
   - 辅助：`侧边栏可管理所有文件夹与笔记`
3. **模板**（节标题 `从模板开始`）
   - 技术开发文档 — 接口说明、故障排查
   - 学习教程笔记 — 知识点清单、复习提纲
   - 日常随笔计划 — 工作计划、随手记录
   - Agent 提示词 — 可复用的 AI 提示模板
4. **轻提示**
   - 笔记保存在 uTools 本地数据库，可在「文件」中导出或备份
   - 深色 / 浅色主题请到右上角设置中切换
   - 文件夹右侧数字 = 该文件夹笔记总数
5. **示例库入口**：`一键导入示例知识库`

Phase A 只做第 1、2 层 + 一行存储说明 +「从侧边栏打开」（见原型 02）。

### 6.4 引导文案（Phase C，对齐原型 03）

| 步 | 锚点 | 文案 |
| --- | --- | --- |
| 1 | 顶栏「+ 新建」 | 点击创建第一篇 Markdown 笔记 |
| 2 | 侧栏「我的文件夹」 | 所有笔记自动保存在本地，不会丢失 |
| 3 | 顶栏「搜索」 | 支持全文检索所有笔记内容 |

底部控件：`1 / 3`、`跳过`、勾选 `不再展示新手引导`。

原始建议里的「3 秒自动消失」**不采用**；以原型 03 的可控引导为准。

### 6.5 示例知识库（Phase D，对齐原型 04）

在「我的文件夹」下创建（若不存在）：

| 文件夹 | 建议内容 |
| --- | --- |
| 技术学习笔记 | 2 篇示范（如接口文档、故障排查） |
| AI Agent教程 | 3 篇示范（含「提示词模板示例」，导入后默认打开此篇） |
| 随笔归档 | 1 篇示范 |

「最新 / 我的文件夹 / 回收站」保持系统结构，不新建同名系统节点。

导入成功后：侧栏展开对应文件夹，打开一篇示例笔记；此时状态栏允许显示字数。

### 6.6 约束

- 遵循 `AGENTS.md`：空态 UI 放 `src/components/`，模板 / 示例正文放 `src/constants/`，引导状态放 `src/composables/` + `AppSettings`，禁止把编排堆进 `App.vue`
- 类型走 TypeScript，禁止无理由 `any`
- 平台能力仍经 `window.markflow`，不在 Vue 里扩散 Node API
- TDD：先写测试再改行为
- 视觉：主色 `#5243E8`，侧栏默认 260px，字体栈 Inter；不引入新 UI 库

- [ ] 空态具备四层结构与 4 张模板卡，文案与原型 01 一致

## 9. 成功指标

本项为首次体验优化，插件内无 DAU 埋点。交付以定性验收为准：

- 空库首启不再「直接进编辑器里的欢迎稿」
- 评审对照原型 02（A）/ 01（B）/ 03（C）/ 04（D）无结构性偏差
- 用户能从空态独立完成：新建、导入、从模板创建、（可选）导入示例库

## 10. 风险（产品侧）

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 老用户怀念自动欢迎笔记 | 有人把欢迎稿当教程 | 顶栏「新手教程」按需打开；不每次启动新建 |
| 存储文案仍写路径 | 原始建议含伪路径，实现时易抄错 | 架构测试禁止 `Documents/MarkFlow`；文案收口常量 |
| 示例库污染用户库 | 写入真实文件夹 | 仅点击触发、幂等、可进回收站 |
| 空态与「关光标签」抢同一 UI | 老用户被模板打扰 | E6：非空库隐藏模板强推与示例库 |
| `App.vue` 膨胀 | 四层空态 + 引导全堆页面 | 技术方案强制拆组件 / composable |
